# mf_u_gudril_cool_one_line_best_li_1_1156

A program that writes one short text for make.fun's bounty `u-gudril-cool-one-line-best-line-b8c41f4d`. Python 3.13, standard library only, no network: `main.py` holds the line as a single string constant, asserts it is between 1 and 280 characters, creates the output folder, and writes `entry.txt` there byte for byte with no trailing newline.
